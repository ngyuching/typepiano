# 音符花園 Note Garden

繁體中文鋼琴識譜練習，支援 C2–C6、自訂音域、三種譜號、升降記號、30 題與無限練習。無後端，設定保存在瀏覽器本機。

## 執行

需要 Node.js 20.19+ 或 22+。

```sh
npm install
npm run dev
```

開啟終端顯示的本機網址。`npm run build` 建置至 `dist/`；`npm test` 驗證音高、譜面位置、出題與作答流程。

## 操作

- 看綠色標記的音符，點擊對應的琴鍵；音名及八度皆須正確。
- 白鍵快捷鍵：1–7 對應 C–B。黑鍵：Q/W/R/T/Y 對應 C♯/D♯/F♯/G♯/A♯。
- 左右方向鍵切換電腦鍵盤的作答八度，預設第 4 八度。琴鍵綠色底線表示目前作答八度。
- 初始音域為 C3–C5，混合譜號、自然音、30 題。C4 以上用高音譜號，以下用低音譜號。
- 音域或出題設定變更會開始新一輪。若自然音模式只選單一黑鍵，上限自動擴展至下一個白鍵。
- 範圍內只有一個音高時允許連續重複。黑鍵升降寫法按音高逐次交替。
- 每題獨立顯示譜號與升降記號，不套用前題的臨時記號。這是識譜題列，不是有小節結構的樂曲。
- 第一次有效作答開始計時；首次答對率為未曾答錯的題數除以已完成題數。
- 音訊由 Web Audio 合成；窄螢幕可橫向捲動樂譜與琴鍵，不會自動移至答案。

音樂符號採用系統的 Segoe UI Symbol／Apple Symbols 字型，文字可使用 Google Fonts（離線時使用系統字型）。

## ABRSM 識譜分級

Grade 1：C/G/D/F 大調、高低音譜號及中央 C。Grade 2：加入 A/B♭/E♭ 大調及 a/e/d 小調、上下兩條加線。Grade 3：四升四降內大小調及更寬加線音域。Grade 4：五升五降、中音譜號、重升重降。Grade 5：六升六降、次中音譜號。Grade 6–8 是本站識譜加強，使用完整調號與四譜號，易混淆題比例分別約為 30%／50%／70%；不代表完整高級樂理考試。

分級依據：[ABRSM 官方 1–5 級樂理大綱](https://www.abrsm.org/sites/default/files/2023-09/music-theory-syllabus-outline-grades-1-5-from-2020.pdf)。本工具僅練音高辨讀，不包含節奏、音程、和聲、對位或創作考核。音域及挑戰比例是本站教學設計。

選級別會套用音域與建議設定；手動改音域或譜號會切回自訂模式。開啟每行不同調號時，每行十題採同一調號與譜號，相鄰行調號不同（狹窄自訂音域只有一個可用調號時例外）。每題用分隔線重設臨時記號，調號持續適用；還原、單升降與重升降均直接指定本位音的變化，並非在調號基礎上再加一次。答對後顯示拼寫與實際音高。

## Web MIDI 鍵盤

以支援 Web MIDI 的 Chrome／Edge，透過 localhost 或 HTTPS 開啟，接上 USB MIDI 鍵盤後按「連接 MIDI」並允許瀏覽器權限。可選所有輸入或指定裝置；支援熱插拔。接收所有 MIDI 通道的 Note On，忽略零力度 Note On、Note Off 與踏板訊息。按實際琴鍵音高作答，不受畫面快捷鍵八度設定影響。只申請一般 MIDI 存取，不要求 SysEx，也不傳送 MIDI 輸出。

無裝置、拒絕權限及不支援瀏覽器均有提示；中斷連線會移除訊息監聽。測試涵蓋模擬 MIDI 訊息與熱插拔流程，實體硬體仍需在使用者裝置上驗證。

## 鋼琴視奏訓練

上方「視奏訓練」頁籤或網址 `/#sight` 可進入。設定與最近 20 次完成結果獨立儲存，不影響認音設定。預設 Grade 1、跟拍、雙手、30 秒預覽、60 BPM、一小節預備拍、節拍器與游標開啟。

分級參照 [ABRSM 鋼琴 Practical Grades 2025–2026 第 15–16 頁](https://www.abrsm.org/sites/default/files/2024-06/Piano%202025%20%26%202026%20Prac%20syllabus%2020240524_access.pdf)的核心視奏元素，不是原認音功能的樂理分級。Grade 1 雙手輪流、五指位置；Grade 2 開始雙手同奏；Grade 3 加入雙音與十六分音符；Grade 4 加入 6/8、半音變化與獨立聲部；Grade 5 加入切分與每手雙音；Grade 6 加入三連音、譜號切換與不規則拍；Grade 7 加入 7/8、7/4；Grade 8 加入 12/8 與每手三音。預設長度為 6、6、8、8、12、16、20、24 小節，也可選 4 小節短練。

每首使用單一調性，以動機、主屬和聲與終止式生成原創短曲。譜面使用 VexFlow；臨時記號依小節及音名八度生效，跨小節重設；連結線後段不需要再次起音。左右手對齊，同手和弦不超過八度，兩手不交叉。第一版不包含弱起、延長記號、曲中變速、八度記號、踏板、琶音或裝飾音；不是完整考綱模擬或官方評分。

- 跟拍模式：預覽可試彈或略過，預備拍後持續前進，彈錯不停。使用 MIDI；音高與起音分別計分，不判定放鍵、力度或踏板。雙手同音時每個譜面音需要獨立輸入。
- 慢練模式：同一時點所有必要音彈對才前進，和弦可逐音輸入；休止及延音不需額外按鍵，不評節奏。電腦／畫面鍵盤只作單手慢練輔助。
- 示範播放：依譜面時值與連結線播放所選聲部，聆聽後此曲標為「已聆聽」。重練保留標記，產生新曲會重設。
- 速度單位：複合拍為附點四分音符，其餘按分母使用四分或八分音符；介面顯示 BPM 單位與拍組。預備拍是一整小節。
- 延遲校正：範圍 ±200ms，正值表示從輸入時間扣除該延遲。
- 音高匹配窗為 ±半拍，限制 120–300ms；準拍窗為 ±0.2 拍，限制 80–180ms。每次輸入只配對最近尚未匹配的同音高事件。
- 音高分數 = 匹配音數 ÷（應奏音數＋額外音數）。節奏分數 = 準拍音數 ÷ 應奏音數。錯音輸入包含在額外音內；漏音是尚未配對的應奏音。分手練習只評所選聲部。
- 演奏中鎖定設定；停止、切頁、背景分頁或所選 MIDI 輸入中斷均取消本輪評分，不儲存結果，保留原曲。

`npm test` 驗證所有級別的調性／拍子組合、時值、音域、五指位置、和弦跨度、雙手不交叉、連結線及可控時間的評分。瀏覽器測試腳本為 `scripts/browser-check.mjs` 與 `scripts/sight-browser-check.mjs`，需要 Playwright 及 Microsoft Edge，可用 `PLAYWRIGHT_MODULE` 指定外部 Playwright 模組路徑。測試涵蓋模擬 MIDI；實體鍵盤與各裝置音訊延遲仍須在實際使用環境驗證。
