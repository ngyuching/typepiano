# 視奏生成器 v2 驗證

日期：2026-10-09。比較基準：部署提交 `b1aaa11b075cb45dff164ca27250c098b5a8da51` 的生成器。

## 多樣性

各級固定 C 大調、4/4、原長度，種子 0–99，共 800 首。新版使用最近二十首摘要挑選最多三十個候選；舊版直接依種子生成。兩版本使用相同的音程／相對時值三事件片段及小節節奏集合，計算每首與前二十首的最大 Jaccard 相似度，再按曲目及級別平均。此指標驗證結構多樣性，並非音樂品質分數。

| 結構 | 舊版平均最近相似度 | 新版平均最近相似度 |
|---|---:|---:|
| 右手旋律 | 0.4894 | 0.0578 |
| 雙手節奏 | 0.8058 | 0.6468 |
| 左手伴奏 | 0.9605 | 0.4384 |

各級一百首皆未出現與最近二十首相同的完整音樂指紋。低級伴奏的相似度仍較高，因五指位置、簡單節奏及每手單音限制；不為追求差異而超級。

量測腳本：`npx tsx scripts/generation-quality-check.ts artifacts/generation-baseline.json`。基準 JSON 是修改前生成器以相同級別、種子、強制 C 大調／4/4 生成的八組一百首資料。輸出各級指標、固定種子 20261009 的 MusicXML／JSON 譜例到 `artifacts/`；產物不納入版本控制。

## 自動與視覺驗證

- 27 項單元測試：所有允許調性／拍號各三種種子，以及原有完整組合檢查；小節長度、三連音每組三音、和弦跨度、兩手不交叉及低級五指限制。
- 樂句結構、旋律變奏、和弦所屬和聲、弱位鄰音級進解決、小調導音向上半音解決、避免連續照抄活動小節。
- 去重指紋不受整體移調影響；種子＋調性＋拍號可重現；無效儲存可復原。
- Edge 桌面與手機固定種子 Grade 1–8 譜例，包含 5/8、7/8、12/8；MusicXML 解析、全部事件映射及頁面無外溢。已目視檢查全小節休止與高級手機譜面。
- 模擬 MIDI 慢練完成、和弦逐音光暈、跟拍音高／節奏 100%、+80ms 校正、斷線／背景中止、示範播放生命週期及成績歷史。
- 瀏覽器驗證新曲去重、未完成曲目保存、重新整理後參考歷史、重練不換曲、損壞儲存復原及二十首上限。
- TypeScript 與 Vite 正式建置通過；OSMD 大型延遲載入套件仍有既有的 chunk 大小提示。

## 驗證限制

沒有接上實體 MIDI 鍵盤。示範播放排程與結束流程已測試，但本次沒有完成真人試聽／彈奏評審；和聲與解決規則測試不能代替聽感。保留譜例供後續人工檢查，不能據此宣稱達到真人教材或官方試題品質。
